# 👟 SyntaxWear | E-commerce de Sneakers

> **Status do Projeto:** 🛠️ Em desenvolvimento.

SyntaxWear é uma plataforma de e-commerce moderna e responsiva dedicada à venda de tênis e sneakers de alta performance. O projeto foca em uma experiência de usuário fluida, com design minimalista e totalmente adaptável a dispositivos móveis.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as melhores práticas de desenvolvimento web front-end:

- **HTML5:** Estrutura semântica.
- **CSS3:** Estilização avançada com Grid, Flexbox e Media Queries.
- **JavaScript:** Lógica de interface e interatividade (em expansão).
- **Google Fonts:** Integração com as fontes *Inter* e *Ubuntu*.

## 📂 Estrutura do Projeto

```text
├── assets/          # Imagens, ícones e assets de demonstração
├── components/      # Fragmentos HTML reutilizáveis
├── css/             # Arquivos de estilização modularizados
├── data/            # Arquivos JSON de simulação de banco de dados
├── js/              # Lógica de negócio e interatividade
├── pages/           # Páginas secundárias (Carrinho, Testes)
└── index.html       # Página principal
```
